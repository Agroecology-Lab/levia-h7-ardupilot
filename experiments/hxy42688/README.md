# Experimental HXY42688 support

This directory archives the reverse-engineered backend and diagnostics for the
undocumented HXY/Silan `ICM-42688P`-marked devices originally assembled on
LEVIA H7 prototypes.

It is retained as engineering history only:

- it is not used by the validated dual-BMI270 firmware;
- it is not a drop-in TDK ICM-42688P implementation;
- it was not flight-qualified;
- its device-type allocation was local and must not be submitted upstream
  without coordination with ArduPilot maintainers.

Use the genuine BMI270 configuration in the repository root for new boards.
